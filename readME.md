Natural Disaster App
-------------------------------------------

description
-------------------------------------------
This app, during a natural disaster, takes in the locations of the users ard sorts them based on priority. First responders can access and download this info to find people easily. 

usage notes
-------------------------------------------
User selects whether they are a civilian or a first responder. Civilians don't have to do anything, locations are automatically taken during a disaster. First responders can view/download locations on landing screen. Civilians can enter how damgaged they are on the app, which impacts their ranking on the priority queue. 

technologies
-------------------------------------------
Kotlin Jetpack Compose, backend Express JS
